# Convergent Dental

> Convergent Dental, Inc. is a privately held dental equipment and technology manufacturer headquartered in Waltham, Massachusetts. Its flagship product is Solea, a 9.3 micron CO2 all-tissue dental laser cleared by the FDA for hard tissue, soft tissue and osseous indications, extended by Solea Perioguide, Solea Sleep and Solea Protect. Convergent Dental publishes no public developer program, API documentation, or machine-readable API contract.

## API surface

Convergent Dental publishes no public API as of 2026-08-01. The following were
probed and returned no machine-readable contract:

- No `api.`, `developer.`, `docs.`, `app.`, `portal.` or `my.convergentdental.com`
  host resolves in DNS.
- `/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/api-docs`, `/graphql` on
  both `convergentdental.com` and `www.convergentdental.com`: HTTP 404.
- `/.well-known/agent-card.json` and `/.well-known/agent.json` on every company
  host including `ilovesolea.com` and `soleadoctors.com`: HTTP 404. No A2A agent
  card is published.
- No hosted MCP server, no published `.proto`, no AsyncAPI or documented webhook
  surface, no first-party SDK on npm, PyPI, or any other public registry.
- The GitHub organization `ConvergentDental` exists but has zero public
  repositories and zero public members.

The Solea laser itself is a connected device — Convergent Dental delivers Solea
software updates over Wi-Fi and 4G LTE for remote service and support — but that
telemetry and update channel is not exposed as a documented public API.
